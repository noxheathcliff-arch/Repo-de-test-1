# Necess · L'écrin

App personnelle de liste d'achats pour l'hygiène et la beauté : chaque produit a sa place dans un coffret, et ce qui manque laisse un creux.

- **En ligne** : https://noxheathcliff-arch.github.io/Repo-de-test-1/ (ajoute `?demo` pour des exemples fictifs)
- `identite/` : le travail du skill direction-artistique (cadrage, enquête, territoires, planches, choix, système d'identité)
- `direction.md` : la passation de la direction artistique vers material-design
- `app/` : l'app (HTML, CSS, JS sans build, hors ligne, données sur l'appareil)

Pour publier une mise à jour : copier le contenu de `app/` sur la branche `gh-pages`.
